이렇게 쓰면 좋습니다

LED 전광판은 종이 피켓보다 눈에 잘 띄고, 문구를 바로 바꿀 수 있다는 장점이 있습니다. 콘서트·경기장 응원, 졸업식·생일 파티, 매장의 임시 안내, 아이 운동회, 심지어 차량 고장 시 뒤차에 보여 주는 안내판으로도 쓸 수 있습니다. 휴대폰만 있으면 되니 준비물이 없고, 문구를 고치고 싶을 때도 손가락으로 몇 번 입력하면 끝입니다.

가장 잘 보이는 조합은 검은 배경에 밝은 글자입니다. 흰 배경에 검은 글자는 멀리서 흐릿하게 보이고, 배터리도 더 빨리 닳습니다. 글자 크기는 화면 높이의 30~40% 정도가 적당하며, 문구가 길면 크기를 줄이거나 속도를 올려 한 번에 지나가도록 하세요. 120자를 넘기면 한 바퀴 도는 데 시간이 오래 걸려 읽기 어려워집니다.

문구가 화면보다 짧으면 가운데에 고정되어 한눈에 읽히고, 화면보다 길어지면 오른쪽에서 왼쪽으로 흘러갑니다. 속도 설정은 긴 문구에서 효과가 있습니다.

전체화면으로 전환하면 브라우저의 주소창과 버튼이 사라져 화면 전체가 전광판이 됩니다. 휴대폰을 가로로 돌리면 세로보다 두 배 이상 넓게 보이므로, 응원 문구처럼 짧고 큰 글씨에는 가로 모드를 권합니다. 밝은 낮 야외에서는 화면 밝기를 최대로 올려야 잘 보입니다.

  • 차량 뒤 안내 — 주황 글자 / 검정 배경 / 크게 / 빠르게

자주 묻는 질문

글자가 흐르지 않고 멈춰 있어요.

"멈추기" 버튼이 눌린 상태인지 확인해 주세요. 버튼을 다시 누르면 "재생"으로 바뀌며 문구가 다시 흐릅니다. 문구를 바꾸면 자동으로 처음부터 다시 시작합니다.

전체화면이 안 되는데요.

일부 앱 내부 브라우저(카카오톡·인스타그램 등)에서는 전체화면 기능이 제한됩니다. 크롬·사파리 같은 기본 브라우저에서 열어 주세요.

화면이 꺼지면 어떻게 되나요?

휴대폰이 잠기면 브라우저가 멈추거나 화면이 꺼집니다. 기기 설정에서 화면 자동 꺼짐 시간을 늘리거나, 사용 중에는 화면을 계속 켜 두세요.

입력한 문구가 저장되나요?

아니요. 문구와 설정은 브라우저 안에서만 처리되며 서버로 전송되지 않습니다.
