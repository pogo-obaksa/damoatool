로또 번호 생성기

1부터 45까지, 겹치지 않는 번호 6개. 버튼 한 번이면 뽑힙니다. 피하고 싶은 번호는 제외수로, 꼭 넣고 싶은 번호는 포함수로 정해 두세요.

번호 뽑기

무작위 추첨은 브라우저 안에서만 이루어지며 어디에도 저장되지 않습니다.

뽑힌 번호
1게임 또는 5게임 버튼을 누르면 번호가 나옵니다.

포함수 (0개 선택)

반드시 넣고 싶은 번호 (최대 5개)

제외수 (0개 선택)

빼고 싶은 번호 (최대 39개)

최근 뽑은 번호

    이 생성기는 재미를 위한 도구입니다. 로또 6/45의 1등 확률은 번호 조합 8,145,060가지 중 하나로, 어떤 번호를 고르든 확률은 같습니다.

    로또 번호, 어떻게 고르면 좋을까요

    로또 6/45는 1부터 45까지의 숫자 중 6개를 맞히는 게임입니다. 1등 확률은 8,145,060분의 1로, 자동으로 뽑든 직접 고르든 확률은 완전히 같습니다. 그래서 “이 번호가 더 잘 나온다”는 말은 통계적으로는 근거가 없습니다. 그런데도 사람들이 번호를 고민하는 이유는, 조합마다 느낌이 다르고 같은 번호를 여러 게임에 넣으면 당첨 시 나눠 갖는 금액이 달라지기 때문입니다.

    이 생성기는 1게임과 5게임을 지원합니다. 5게임은 실제 판매점에서 한 장에 5게임을 살 때 쓰는 단위라서, 수동으로 고민하는 시간을 줄이고 싶을 때 편합니다. 한 번에 뽑은 5게임은 서로 겹치지 않게 만들어, 같은 조합이 두 번 나오는 일을 피했습니다. 번호는 오름차순으로 정렬해 보여 주므로, 마킹 용지에 옮겨 적기도 쉽습니다.

    번호를 고르는 습관은 사람마다 다릅니다. 생일이나 기념일 숫자를 넣는 분, 최근에 나온 번호를 피하는 분, 반대로 오랫동안 안 나온 번호를 고르는 분도 있습니다. 포함수·제외수 기능은 그런 습관을 그대로 반영하기 위한 것입니다. 예를 들어 “10번대는 넣고 싶다”면 10~19를 포함수로, “이 번호는 지난주에 나왔으니 빼자”면 제외수로 지정하면 됩니다.

    뽑기 기준

    번호 범위 — 1 ~ 45, 중복 없이 6개
    포함수 — 먼저 넣고 남은 자리를 무작위로 채웁니다 (최대 5개)
    제외수 — 뽑기 대상에서 완전히 빼고 추첨합니다
    난수 — 브라우저의 암호학적 난수(crypto.getRandomValues)를 사용합니다

    포함수를 5개까지 정할 수 있는 이유는, 6개를 모두 지정하면 추첨이 아니라 그냥 번호를 적는 것이 되기 때문입니다. 제외수는 39개까지 고를 수 있어, 남는 번호가 6개 미만이 되면 뽑을 수 없습니다. 포함수와 제외수에 같은 번호를 넣으면 나중에 누른 쪽이 이기고 반대쪽에서는 자동으로 빠집니다.

    번호 공의 색은 실제 로또와 같은 구간을 따릅니다. 1~10은 노랑, 11~20은 파랑, 21~30은 빨강, 31~40은 회색, 41~45는 초록입니다. 마킹 용지에 옮겨 적을 때 구간 색을 함께 기억해 두면 실수를 줄일 수 있습니다.

    재미로 즐기는 방법

    • 가족·친구와 한 장씩 — 5게임을 뽑아 각자 한 게임씩 나눠 갖는 방식이 인기입니다.
    • 기념일 조합 — 생일·결혼기념일 숫자를 포함수로 넣고 나머지를 자동으로 채웁니다.
    • 번호를 적어 두기 — 뽑은 결과는 복사 버튼으로 메모장에 붙여 둘 수 있습니다.
    • 과하지 않게 — 로또는 여가 활동입니다. 감당할 수 있는 금액 안에서만 즐기세요.

    주의할 점

    이 페이지는 번호를 무작위로 만들어 줄 뿐, 당첨을 보장하지 않습니다. 어떤 번호든 당첨 확률은 같고, 과거에 나온 번호가 앞으로 나오지 않을 확률도 달라지지 않습니다. 뽑은 번호는 화면을 닫으면 사라지므로, 필요하면 복사해 두세요. 게임 중독이 걱정된다면 한국도박문제예방치유원(1336)에서 상담을 받을 수 있습니다.

    기준일: 2026년 11월 26일. 동행복권 로또 6/45의 번호 범위(1~45)와 1등 확률(1/8,145,060)을 기준으로 안내했습니다. 구매는 만 19세 이상만 가능합니다.

    자주 묻는 질문

    5게임을 뽑으면 번호가 겹치나요?

    한 번에 뽑은 5게임 안에서는 같은 조합이 나오지 않도록 했습니다. 각 게임 안에서도 번호 6개는 중복되지 않습니다.

    제외수를 많이 넣으면 당첨 확률이 올라가나요?

    아니요. 번호를 줄이면 조합 수가 줄어들 뿐, 게임당 당첨 확률은 같습니다. 제외수는 “이 번호만은 안 넣고 싶다”는 취향을 반영하는 기능입니다.

    포함수에 6개를 넣을 수 없나요?

    5개까지입니다. 6개를 모두 지정하면 자동 추첨이 아니라 직접 번호를 적는 것과 같아서, 한 자리는 무작위로 남겨 둡니다.

    뽑은 번호가 저장되나요?

    아니요. 번호는 화면에만 표시되고 서버로 보내지 않습니다. 화면을 닫으면 사라지므로 복사 버튼으로 따로 보관하세요.

    자동과 수동, 어느 쪽이 유리한가요?

    확률은 같습니다. 다만 같은 번호를 여러 명이 고르면 당첨금을 나눠 갖게 되므로, 인기 조합(1·2·3·4·5·6 같은 연속 번호)을 피하는 편이 기대 금액 면에서는 조금 유리합니다.
